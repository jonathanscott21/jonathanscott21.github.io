Personal Archive Sync

Privacy policy

Effective October 30, 2026. Personal Archive Sync is a personal utility operated by its owner for that owner's Google account. This disclosure describes the local synchronization utility and this informational website.

Google account data and purpose

Using rclone on the owner's Mac, the utility reads Drive file names, identifiers, folder structure, sizes, checksums and managed file contents. It uploads the owner's selected archive files, supporting metadata, documentation, exports and verification manifests. It reads cloud copies to check integrity and may retain previous managed versions when updating files. It does not sell data or use it for advertising or model training. The synchronization command does not send archive contents to an AI service.

The requested Google Drive permission is technically broader than a single folder. The utility pins its configured destination folder and checks for conflicting remote changes; that application setting does not narrow the Google account permission itself.

Storage, sharing and retention

Archive content and sync receipts are kept in the owner's local archive and designated Google Drive folder. OAuth client credentials and tokens are kept in protected local rclone configuration, not in the archive or on this website. The sync utility has no separate hosted backend. File contents and authentication credentials are not published to this GitHub Pages site. Google processes cloud files as the Drive provider; separately authorized tools or uses of the archive are outside this synchronization utility.

The owner controls how long local and cloud files, backups and receipts are retained. Synchronization does not automatically delete cloud files. The owner can remove data using local filesystem and Google Drive controls and revoke access in Google Account's third-party connections. Revoking access does not itself delete previously synchronized files.

This website

This static informational site has no sign-in form, archive access, advertising or analytics scripts added by the app. GitHub hosts it and may process visitor data, including IP addresses, for hosting and security; see GitHub's privacy statement. Do not submit credentials or archive files to this site.

Contact and changes

Contact the app owner through the user-support email shown on the Google consent screen. This policy will be updated if the utility's data practices change.
